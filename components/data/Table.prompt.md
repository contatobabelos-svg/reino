Tabela para dados tabulares densos (relatórios, listagens).

```jsx
<Table columns={["Empresa", "Nicho", "Cidade", "Nota"]} rows={[["Conta Certa Contabilidade", "Contabilidade", "Campinas", "4,8"]]} />
```

Cabeçalho sempre em caixa alta com `letter-spacing` .06em — é ele que dá o ar de painel de controle.

Distribuição em rosca — status de negócios, composição de carteira.

```jsx
<DonutChart label="negócios" segments={[
  { name: "Em andamento", value: 45 },
  { name: "Fechados", value: 35 },
  { name: "Em espera", value: 20 },
]} />
```

Um por painel. Para um único valor de progresso use `ProgressRing`, não uma rosca de um segmento.

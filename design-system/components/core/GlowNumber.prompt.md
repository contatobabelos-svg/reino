Número que acende. Nunca ponha texto corrido nele — só valor e unidade.

```jsx
<GlowNumber value="2.041" size="1.75rem" />
<GlowNumber value="4,6" suffix="★" tone="gold" />
<GlowNumber empty />
```

Enquanto o dado não chega, use `empty`: é assim que o produto mostra carregamento, sem esqueleto animado.

Nível do afiliado. Anda junto do `AffiliateLink`: o link para copiar, o nível para motivar.

```jsx
<AffiliateLevel level="Prata" indicados={7} proximo="faltam 3 para Ouro" progress={70} />
<AffiliateLevel level="Prata" indicados={7} compact />
```

O dourado aqui é o mesmo dos títulos de nobreza — nível de afiliado é reputação, não ação.
